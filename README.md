## Project

This is a simple Event Countdown Timer web application made using Django.

The project allows users to view an event and see the remaining time until the event starts.

## Features

- Add an event
- Enter event name, date and time
- Display event details
- Live countdown timer
- Countdown updates every second
- Django admin panel

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## How to Run

Install Django:

    pip install django

Run migrations:

    python manage.py migrate

Start the server:

    python manage.py runserver

Open the website:

    http://127.0.0.1:8000/

## Django Admin

Admin panel:

    http://127.0.0.1:8000/admin/

Create an admin account:

    python manage.py createsuperuser

## How It Works

Django stores the event name, date and time in the SQLite database.

The event details are displayed on the webpage, and JavaScript calculates the remaining time and updates the countdown every second.
